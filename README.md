# Automação UI com Cypress

Projeto de automação de testes E2E utilizando Cypress.

## Tecnologias utilizadas
- Cypress
- JavaScript
- Node.js

##  Cenários implementados
- Cenário positivo: acessar o site
- Cenário positivo: clicar em comandos
- Cenário negativo: validar elemento inexistente

## Como executar o projeto
1. Clonar o repositório
2. Instalar as dependências:
   npm install
3. Executar o Cypress:
   npx cypress open
