# Automação UI com Cypress

![Cypress](https://img.shields.io/badge/tested%20with-Cypress-04C38E.svg)

Projeto de automação de testes E2E utilizando Cypress.

## Tecnologias utilizadas
- Cypress
- JavaScript
- Node.js

##  Cenários implementados
- Cenário positivo: acessar o site
- Cenário positivo: clicar em Commands
- Cenário negativo: validar elemento inexistente

## Como executar o projeto
1. Clonar o repositório
2. Instalar as dependências:

```bash
npm install
```

3. Executar o Cypress:

```bash
npx cypress open
```

## Objetivo

Este projeto foi desenvolvido como prática de automação de testes E2E utilizando Cypress, com foco em validação de navegação, interação e cenários negativos.
